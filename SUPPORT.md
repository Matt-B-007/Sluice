# Getting help with Sluice

**Questions, chat, or a problem you are not sure is a bug:** join the [Discord server](https://discord.gg/awDvJ5Vj2S) and use
the Sluice support forum.

**A bug:** save a bug report first, with *Help > Save bug report...* in the window or `sluice --report` in a terminal. Then
either:

- open a **private ticket** on the Discord server and attach the file there (the best place: only you and the maintainer see
  it), or
- open an [issue on GitHub](https://github.com/Matt-B-007/Sluice/issues). Issues are **public**: describe the problem there and
  attach the report only if you are happy for anyone to read it.

Please do not post the report in the public forum. Sluice replaces your user name, computer name, home folder, addresses,
serial numbers and Steam account number in it, but it still lists device names and app names. Say what you did, what you
expected, and what happened (silence, crackling, the wrong output...).

**A security problem:** see [SECURITY.md](SECURITY.md); please do not report it in public.

Sluice is maintained by one person in spare time. Only the newest release is supported: update with
*Settings > Check for updates* before reporting.
